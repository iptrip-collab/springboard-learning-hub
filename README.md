## 📖 About

**Springboard Learning Hub** is a responsive educational website in the spirit of modern online learning platforms. It is designed for three audiences: **students**, **corporate employees** and **working professionals**.

The whole experience is built around a calm, stress-relieving, spring-like mood. It uses a soft spring colour palette, gentle animations and a clean, professional layout that is easy to read and easy to understand.

> **Design brief:** a professional, easy-to-read educational website of 7–8 pages, with a custom logo and a creative name, posters and imagery, relevant animations, and no pricing shown on course posters. Each course poster carries a one-line description of what the course offers.


 Features

- 🎨 **Spring colour palette** – fresh, calm and easy on the eyes
- 📱 **Fully responsive** – works across mobile, tablet and desktop
- 🖼️ **Course posters** – visual cards for each course, with a short one-liner under each poster describing what it offers
- 🚫 **Clean course presentation** – no pricing on the front-facing posters
- 🌸 **Smooth animations** – subtle motion that supports the relaxing spring vibe
- 🏷️ **Custom brand identity** – original name and logo
- 📄 **7–8 focused pages** – a compact, easy-to-navigate site structure
- 👥 **Built for everyone** – students, corporate teams and working professionals

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (latest LTS recommended) and npm, **or** [Bun](https://bun.sh/)
- [Git](https://git-scm.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/iptrip-collab/springboard-learning-hub.git

# 2. Move into the project folder
cd springboard-learning-hub

# 3. Install dependencies
npm install
# or: bun install

# 4. Start the development server
npm run dev
# or: bun run dev
```

Then open the local URL shown in your terminal (usually `http://localhost:3000` or `http://localhost:5173`).

### Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |

| `npm run preview` | Preview the production build locally |

| `npm run format` | Format the code with Prettier |
